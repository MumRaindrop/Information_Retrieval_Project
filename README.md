# Information_Retrieval_Project
Implement the basics of an information retrieval system using a scrapy crawler, indexer, flask app, and a simple Web UI for controlling it all.

Everything in the project can be run locally. Simply inside the processor, run the flask app using `flask --app app run. This will then prompt the user with a WebUI they can open to perform any of the operations. The user can begin a crawl based on a url, max pages, and max depth then the system will crawl and output results to a json file holding urls and the html of each page. The user can then build the index after the crawl has completed, this will rewrite the inverted index based on the new pages crawled, it will output this as a json file formatted as urls and the inverted index which has the structure, term: (doc_id, tf_idf), ... The user then can query the system using the text box or uploading a csv file which contains query as the first item. The system will then return the top 5 results in terms of cosine similarity between the query and document vectors.
